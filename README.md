# GoonReader
An unofficial, read-only Android client for reading fanfiction from [Archive of Our Own (AO3)](https://archiveofourown.org/).
## Features
- **Library** — a persistent, offline-ready collection of your works with reading progress, categories, and stats
- **Updates** — detects new chapters automatically and highlights what's new
- **Browse & search** — AO3's own filters, tags, and ratings, all inside the app
- **Reader** — tap zones, themes, custom fonts and colours, gestures, TTS read-aloud, scroll and paged modes
- **Downloads** — optional per-chapter / per-work downloads for offline reading
- **History, bookmarks, comments** — read chapter comments without leaving the app
- **Backups** — export and import your library as JSON
## Usage
Add a work by pasting its AO3 link (or from Browse), and it lands in your Library. Open a chapter to read it — content is cached so reopening is instant, and even works offline for downloaded chapters. Turn on updates to fetch new chapters automatically.
> **Note:** GoonReader is an unofficial client with no backend. It fetches and parses public AO3 pages and has no data collection, ads, or telemetry.
